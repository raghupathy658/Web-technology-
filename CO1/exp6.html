About XHTML

XHTML stands for Extensible HyperText Markup Language. It follows stricter rules than normal HTML.

XHTML requires elements to be properly nested, attributes to be quoted, and empty elements to be properly closed.

XHTML Rules Used

  • All HTML tags are written in lowercase.
  • All attributes are written inside quotes.
  • All elements are properly closed.
  • Elements are properly nested.
  • Empty elements are self-closed.
