🌐 Images, Hyperlinks & Iframes

Web Technology - Experiment 8

🎯 Aim

To create a webpage using images, hyperlinks and iframes with appropriate width, height and alternative text.

🖼️ 1. Image

The HTML <img> tag is used to display an image on a webpage.

The alt attribute provides alternative text if the image cannot be displayed.

🔗 2. Hyperlinks

The HTML <a> tag is used to create hyperlinks to other webpages or websites.

🔍 Google 📖 Wikipedia 🌐 W3C

📺 3. Iframe

The <iframe> tag is used to embed another webpage inside the current webpage.

💻 HTML Tags Used

<img src="image.jpg" alt="College Building" width="400" height="250" >
<a href="https://www.google.com" target="_blank" > Google </a>
<iframe src="https://www.w3.org/" width="800" height="400" title="W3C Website" > </iframe>

📌 Summary

<img> → Displays images.

<a> → Creates hyperlinks.

<iframe> → Embeds another webpage.

width → Specifies the width.

height → Specifies the height.

alt → Provides alternative text for images.
