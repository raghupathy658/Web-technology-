🔧 Debugging Techniques

1. Console: Open Browser Developer Tools using F12 or Ctrl + Shift + I.

2. Console.log(): Used to display variable values and program execution information.

3. debugger: Pauses JavaScript execution at a particular line.

4. try...catch: Used to handle JavaScript errors without crashing the application.

5. Elements Panel: Used to inspect and modify HTML and CSS.

6. Sources Panel: Used to inspect JavaScript code and set breakpoints.
