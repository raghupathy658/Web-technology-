Concurrency Concepts Explained

Servlet Concurrency & Shared Variables Instance variables belong to the single Servlet instance and are shared across all worker threads. Local variables inside doGet() belong to the thread stack and are naturally thread-safe.
Race Condition & Testing A race condition occurs when concurrent threads execute non-atomic read-modify-write operations simultaneously. Note: Concurrent client requests (e.g. Apache JMeter or load test) are required to expose race condition bugs in production.
AtomicInteger Solution Provides lock-free, thread-safe atomic operations using hardware CAS (Compare-And-Swap) instructions, guaranteeing correctness under high concurrency.
Synchronization Alternative Using synchronized(this) blocks or methods guarantees mutual exclusion, but can introduce performance bottlenecks under heavy load compared to AtomicInteger.
